# 上海配送站外显服务地图

这是一个可直接打开和演示的静态前端原型，当前已经按 52 个阳光基地站做了上海地图标注，并额外加入了 1 个调配中心点位。

- 打开页面直接展示整张上海底图
- 地图上展示全部基地站点位
- 点击任意点位弹出基地信息
- 单独展示“阳光201调配中心”点位
- 顶部“基地站 / 调配中心 / 覆盖区划”支持点位筛选
- 支持给指定基地站配置工作任务样板

## 本地运行

在项目目录执行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：页面样式与地图视觉
- `stations-data.js`：52 个基地站的点位与基础信息，含可选任务样板字段
- `app.js`：地图交互、点位切换与浮窗逻辑

## 说明

当前点位数据来自用户提供的《阳光基地劳动产品摸底调查表(2026年首批20260428).xls》，字段包括区划、机构名称、机构地址、援助对象人数。
