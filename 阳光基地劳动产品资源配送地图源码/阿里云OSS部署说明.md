# 阿里云 OSS 部署说明

适用于当前这个静态网站项目：

- `index.html`
- `404.html`
- `app.js`
- `styles.css`
- `stations-data.js`

## 推荐方式

使用阿里云 **OSS 静态网站托管 + 自定义域名**。

原因：

- 这是纯静态前端项目，不需要服务器运行时。
- 维护成本比 ECS 更低。
- 适合通过链接直接分享给其他人访问。

## 注意事项

1. 直接使用 OSS Bucket 默认域名访问 HTML 时，浏览器可能会下载文件，而不是直接打开网页。
2. 如果要让别人通过网页链接直接打开，建议绑定 **自定义域名**。
3. 如果 Bucket 在中国内地地域，绑定的网站域名需要完成 **ICP备案**。

## OSS 控制台要配置的内容

1. 创建 Bucket
2. 上传本目录静态文件
3. 打开“静态页面”
4. 默认首页设置为：

```text
index.html
```

5. 默认 404 页面设置为：

```text
404.html
```

6. 绑定自定义域名
7. 在 DNS 控制台做 CNAME 解析
8. 如需 HTTPS，再给该域名绑定证书
